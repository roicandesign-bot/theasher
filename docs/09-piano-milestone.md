# 09 · Piano di implementazione per milestone

Ogni milestone chiude con: `npm run check` verde (lint, typecheck, format, build, test), screenshot ai viewport principali in `design/screenshots/`, commit sul branch di lavoro, aggiornamento di `design/PROGRESS.md`. Le milestone sono sequenziali; ognuna lascia il sito **funzionante** e verificabile.

| #   | Milestone                  | Cosa produce                                                                                                                                                                                                                                                                                                                                                                                             | Criterio di accettazione                                                                                                       |
| --- | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| M0  | **Fondazione**             | Next.js 16 App Router, TS strict, Tailwind 4 con token The Hasher, font self-hosted, Prisma + migrazione iniziale completa, seed demo (categorie, 3 prodotti, varianti, lotti, lab report, mercati, spedizioni, coupon, pagine, FAQ, admin demo), env validate, logger, error handling, Docker, CI con test, screenshot script adattato                                                                  | `npm run check` e `npm run test` verdi; DB migrato e seedato in sessione; styleguide `/styleguide` con token e componenti base |
| M1  | **Design system e layout** | componenti UI, Header/Footer/InfoBar, menu mobile, age gate, cookie banner, market switcher, 404 nel brand, i18n con 5 lingue (UI)                                                                                                                                                                                                                                                                       | screenshot a 390/834/1440 approvati dal responsabile design                                                                    |
| M2  | **Catalogo**               | home completa, shop/categorie/new drops/best seller con filtri in URL, ricerca predittiva, pagina prodotto completa (gallery, formati, prezzo/g, lab report, FAQ, correlati, recensioni verificate, visti di recente), wishlist, SEO (metadata, hreflang, sitemap, JSON-LD)                                                                                                                              | flusso catalogo → prodotto navigabile in 5 lingue; Lighthouse ≥ 90/95/95/95 su home, categoria, prodotto                       |

Ordine di lavoro nelle sessioni: una milestone alla volta; dentro ogni milestone si mostra prima la parte visibile (pagina/screenshot), poi si completano test e documentazione.
