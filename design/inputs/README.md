# Input di design

Metti qui tutto ciò che serve a Claude per riprodurre il design:

- export PNG/JPG delle schermate Figma (una per pagina, meglio se anche la versione mobile)
- logo (SVG o PNG con sfondo trasparente)
- moodboard, screenshot di siti di riferimento
- brand book o palette (anche una foto va bene)

Convenzione nomi: `pagina-viewport.png` (es. `home-desktop.png`, `home-mobile.png`), `logo.svg`, `ref-nomesito.png`.
