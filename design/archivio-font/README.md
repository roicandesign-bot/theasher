# Archivio font The Hasher

- `THE-HASHER-archivio-font.pdf`: il documento da condividere (8 pagine, A4 orizzontale).
- `archivio-font.html`: la sorgente. Per rigenerare il PDF dopo una modifica:
  aprire l'HTML con Playwright/Chromium e stampare in PDF con sfondi (vedi la cronologia di progetto).

I font usati sono gli stessi del sito, dai pacchetti fontsource in `node_modules` (licenza SIL OFL 1.1).
