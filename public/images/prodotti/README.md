# Pack dei prodotti

Generati da `scripts/pack-hasher.py` partendo dalla bozza del pack preroll di Lorenzo
(`design/inputs/preroll/pack-bozza.png`): stessa grafica, scritte prese dal catalogo
(linea, percentuale, nome, tipo, genetica, formato), scontorno e sfondo scuro con alone giallo.

Per rifarli o aggiungerne uno: modificare la lista `PACK` in fondo allo script e lanciare
`python3 scripts/pack-hasher.py` (oppure `python3 scripts/pack-hasher.py <nome-file>`).
Sono render di progetto, non foto di prodotti esistenti.
